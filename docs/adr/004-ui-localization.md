# ADR-004. Русский интерфейс и отдельный слой локализации

Решение: русский язык по умолчанию, единственный язык MVP, без переключателя.
Все интерфейсные тексты централизуются в каталоге `frontend/src/i18n/locales/ru`;
компоненты обращаются к типизированному интерфейсу переводов и форматтеров.
Словарь и правила — [ui-language.md](../ui-language.md).

Причина: обязательные требования 35–36, единая терминология, возможность
добавлять языки без переписывания компонентов. API возвращает стабильные
машинные коды, а не английские пользовательские сообщения и не исключения.

Альтернативы: русские строки прямо в JSX проще начать, но сложно проверять
и расширять; тексты из API смешивают представление и бизнес-контракт;
полноценная многоязычная настройка в MVP создаёт ненужный интерфейс.

Цена: каталог ключей, таблицы enum/ошибок, проверка полноты и отдельная
локализация библиотек/статических страниц. Это обязательная работа, не
дополнительное улучшение после реализации страниц.

Миграция: добавить каталог следующего языка по тому же типу ключей, проверить
полноту и форматирование, затем отдельно спроектировать настройку языка.
Компоненты остаются прежними. Машинные значения API и БД не переводятся.
