Статус каждого решения указан в его документе. Документы фиксируют принятые архитектурные ограничения и причины выбора решений.

- [ADR-001: фоновые задачи, брокер и планировщик](001-background-processing.md)
- [ADR-002: приём, MIME и вложения](002-ingestion-and-storage.md)
- [ADR-003: данные, шаблоны и масштабирование](003-data-and-templates.md)
- [ADR-004: русский интерфейс и локализация](004-ui-localization.md)
- [ADR-005: сеансы, права и аудит](005-authentication.md)
- [ADR-006: права PostgreSQL и разделение секретов](006-database-privileges.md)

Первичный анализ покрывает Celery/Dramatiq/ARQ, Redis, планировщик, SMTP,
Syslog, MIME, вложения, объединение повторов, сводки, очистку, секционирование,
повторную отправку, неотправленные уведомления, шаблоны и масштабирование.
