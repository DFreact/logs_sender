# ADR-005. Сеансы, права и аудит

Статус: принято для этапа 2. Дата: 29 сентября 2026 года.

Непрозрачный случайный сеанс хранится в HttpOnly/SameSite=Strict cookie,
его SHA-256 — в PostgreSQL. Срок жизни абсолютный, 8 часов по умолчанию.
Роль проверяется по действующему членству при каждом запросе. JWT не используется:
мгновенный отзыв и небольшое число локальных пользователей важнее автономной
проверки токена. Пароли — Argon2id с 64 МиБ памяти, тремя проходами и четырьмя
потоками; проверка неизвестной учётной записи использует фиктивный хеш.

CSRF: проверка точного Origin и подписанный токен до входа; после входа —
токен, связанный с текущим сеансом. Ключ подписи хранится отдельно от БД.
Вход заменяет прежний сеанс; выход, смена пароля, отключение или изменение роли
отзывают соответствующие сеансы. Токены не попадают в localStorage и журналы.

Лимит входа считается атомарно в PostgreSQL отдельно по адресу и нормализованному
имени пользователя. Это переживает рестарты и работает при нескольких процессах,
не требует Redis до этапа 3. Ограничиваются все попытки; 10 на имя и 30 на адрес
за 5 минут по умолчанию. Ключи счётчиков — HMAC, без открытых имён и адресов.
Недостаток — обращения к БД и возможность временного ограничения чужой учётной
записи. Старые счётчики и истёкшие сеансы очищаются ограниченными пакетами.

Изменения пользователей и аудит фиксируются одной транзакцией. Блокировка
строки команды сериализует административные изменения и не позволяет удалить
последнего активного администратора при гонке. Пользователь отключается,
физического удаления через API нет. Team присутствует в фильтрах и связях,
полноценная многопользовательская изоляция команд не заявляется.

Cookie по умолчанию Secure, допустимы только HTTPS-origin. Локальный стенд
сохраняет HTTP на loopback через явно включённый режим разработки; такой режим
валидирует, что разрешённые адреса — localhost/loopback. Для сетевой установки
нужны TLS и отключение этого исключения. Адрес клиента доверяется прокси только
из явно перечисленной сети, Nginx перезаписывает входящий заголовок адреса.

Первый администратор создаётся локальной интерактивной командой; пароля по
умолчанию нет. Браузерные тесты используют отдельную временную БД/схему и
случайные учётные данные, не создавая тестовые аккаунты на рабочем стенде.

Миграция позже: транспорт сеанса и хеши сохраняются, при появлении внешней
аутентификации меняется проверка личности; локальные права остаются общими.
Основания: [рекомендации OWASP по аутентификации](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html),
[защите CSRF](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)
и [параметры Argon2](https://argon2-cffi.readthedocs.io/en/stable/parameters.html).
