# Центр событий и уведомлений

Корпоративное приложение для установки в локальной сети: приём событий по SMTP
и REST, правила обработки и доставка уведомлений. Версия **0.12.2**, схема БД **0012**.
Интерфейс полностью на русском языке.

## Возможности

- Источники, ключи приёма и инструкции подключения отправителей.
- Поиск и фильтрация событий, вложения, объединение повторов.
- Правила обработки, проверка на тестовом событии, подтверждение и эскалация.
- Каналы SMTP, MAX, Telegram и HTTP; настройка подключений и смена секретов.
- Шаблоны, сводки, очередь доставки, повторные отправки и история попыток.
- Пользователи, права доступа, журнал аудита и состояние системы.
- Сроки хранения, резервное копирование и восстановление.
- Светлая и тёмная тема, настройка цветовой гаммы для всей установки.

Доступность каналов определяется сетевой политикой организации. Строгий профиль
запрещает внешний трафик; доступ к MAX включается отдельно по разрешённым адресам.
Пароли и токены каналов хранятся в зашифрованном виде и не возвращаются интерфейсу.

## Установка без интернета

В разделе **Releases** репозитория предназначены для размещения два комплекта:
готовые образы с установщиком и исходники с зависимостями для автономной сборки.
Обычный архив исходников GitHub не содержит образов и зависимостей.

Целевая платформа — Linux x86-64. На сервере заранее должны быть установлены
Python 3.7+, Docker Engine, Compose v2 и nftables. Пакеты этих системных
инструментов в комплект не входят.

1. Перенесите архив готовых образов и файл `SHA256SUMS` на сервер.
2. Проверьте контрольную сумму архива командой `sha256sum --ignore-missing -c SHA256SUMS`.
3. Распакуйте архив и выполните `python3 admin.py verify` из каталога комплекта.
4. Выполните настройку сети и установку по [инструкции](docs/offline-operations.md).

При установке создаются новые секреты. Встроенного пароля администратора нет:
первая учётная запись создаётся интерактивно после запуска.

## Разработка и проверка

Сервер: Python, FastAPI, SQLAlchemy/Alembic, PostgreSQL, Redis и Dramatiq.
Интерфейс: React, TypeScript и Vite. Развёртывание: Docker Compose.

[Настройка окружения и команды проверок](docs/local-development.md).
Для сборки без сети используйте комплект исходников с зависимостями;
Dockerfile с окончанием `.online` предназначены для подготовки зависимостей.
Локальные настройки, секреты, данные, отчёты запусков и архивы исключены из Git.

## Ограничения

Проверки выполнены на Ubuntu x86-64. Совместимость с Astra Linux 1.7 и 1.8
и реальная доставка в MAX требуют испытаний на целевых серверах и с токеном бота.
Полная изоляция компаний не реализована. Промышленная пропускная способность
требует измерения на согласованном профиле нагрузки. Остаточные предупреждения
о пакетах ОС требуют отдельной оценки; выпуск не является аттестацией безопасности.
